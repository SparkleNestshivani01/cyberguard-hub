# CyberGuard Hub

A full-stack Security Operations Center (SOC) dashboard that combines Machine Learning anomaly detection with password security analysis.

## Features
- **AI Anomaly & Threat Scanner**: Isolation Forest model evaluating network traffic.
- **Password Entropy Engine**: Information entropy calculation and policy evaluation.
- **Testing Suite**: Automated testing via pytest.

## Tech Stack
Python, Flask, Scikit-Learn, Pandas, NumPy, Tailwind CSS, PyTest

## Quick Start
1. **Clone repo**: `git clone https://github.com/SparkleNestshivani01/cyberguard-hub.git`
2. **Install dependencies**: `pip install flask pandas numpy scikit-learn pytest`
3. **Run app**: `python app.py`
4. **Run tests**: `pytest`
